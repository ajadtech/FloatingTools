# Floating Tool — নতুন প্রজেক্ট সেটআপ (স্টেপ বাই স্টেপ)

## ১. নতুন প্রজেক্ট খোলা
1. Android Studio ওপেন কর → **New Project** → **Empty Views Activity** → ভাষা **Kotlin** সিলেক্ট কর।
2. প্রজেক্ট নাম দাও `FloatingTools`, প্যাকেজ নেম দাও `com.azad.floatingtools` (বা তোমার পছন্দমতো, শুধু সব ফাইলে একই নাম বসাতে হবে)।
3. প্রজেক্ট তৈরি হয়ে গেলে, এই zip-এর ভেতরের ফাইলগুলো যার যার জায়গায় কপি করে বসাও (নিচে ম্যাপিং দেওয়া আছে)।

## ২. ফাইল কোথায় বসবে
এই zip-এর ফোল্ডার স্ট্রাকচারটাই Android Studio প্রজেক্টের স্ট্রাকচারের মতো করে সাজানো। সরাসরি কপি করে বসিয়ে দিলেই হবে:

```
app/build.gradle.kts                        → তোমার প্রজেক্টের app/build.gradle.kts-এর সাথে মিলিয়ে নাও
app/src/main/AndroidManifest.xml             → একই জায়গায় replace কর
app/src/main/java/com/azad/floatingtools/... → একই প্যাকেজ স্ট্রাকচারে বসাও
app/src/main/res/...                          → একই res ফোল্ডারে বসাও
```

> প্যাকেজ নেম যদি তুমি অন্য কিছু দাও, তাহলে প্রতিটা `.kt` ফাইলের উপরের `package com.azad.floatingtools` লাইন আর `AndroidManifest.xml`-এর `namespace`/`applicationId` বদলে নিতে হবে।

## ৩. লোগো বসানো
`logo_source/app_logo_source.png` — এটাই তোমার দেওয়া আসল লোগো।
1. Android Studio-তে `res` ফোল্ডারে রাইট-ক্লিক → **New → Image Asset**।
2. Icon Type: **Launcher Icons (Adaptive and Legacy)**।
3. Foreground Layer-এ `app_logo_source.png` বেছে নাও (ব্যাকগ্রাউন্ড ট্রান্সপারেন্ট না থাকলে Trim/Padding ঠিক করে নাও)।
4. **Finish** করলেই সব সাইজের (mdpi থেকে xxxhdpi) আইকন অটো জেনারেট হয়ে যাবে এবং `ic_launcher` রিপ্লেস হয়ে যাবে।

## ৪. পারমিশন (ফ্লোটিং বারের জন্য জরুরি)
ফ্লোটিং বার (overlay) দেখানোর জন্য "Display over other apps" পারমিশন ইউজারকে ম্যানুয়ালি দিতে হয়। `MainActivity`-তে এই চেক/রিকোয়েস্ট যোগ করতে হবে (এখনো যোগ করা হয়নি, পরের ধাপে দিব):

```kotlin
if (!Settings.canDrawOverlays(this)) {
    val intent = Intent(Settings.ACTION_MANAGE_OVERLAY_PERMISSION, Uri.parse("package:$packageName"))
    startActivity(intent)
}
```

## ৫. যা যা রেডি করে দেওয়া হলো
- নতুন Bottom Navigation: **Home** + **My Floating Apps**
- Home পেজ: গ্রেডিয়েন্ট হেডার, সার্চ বক্স (ডানে আইকন, হিন্ট "Search your favorite app"), আর তিনটা সেকশন (Your own apps / All online apps / Your own web app supported)
- My Floating Apps পেজ: অ্যাপ লিস্ট + নিচে Telegram ও Facebook আইকন (ক্লিক করলে লিংক খোলে)
- ফ্লোটিং বার সার্ভিস (`FloatingBarService.kt`): ট্যাপ করলে আগের মতোই খোলে, আর এখন প্রেস করে ধরে ড্র্যাগ করলে বারটা যেকোনো জায়গায়/মাঝখানে নেওয়া যাবে
- গ্রেডিয়েন্ট থিম কালার (নীল → বেগুনি → নেভি) লোগোর সাথে মিলিয়ে
- **নতুন: `FloatingWebBubbleService.kt`** — Home বা My Floating Apps-এ যেকোনো "Web ✓" অ্যাপে ক্লিক করলে সেটা একটা ফ্লোটিং উইন্ডোতে (YouTube ইত্যাদি) খুলবে:
  - উপরে টাইটেলবার ধরে টেনে নড়ানো যাবে
  - মাইনাস বাটনে ক্লিক করলে ছোট গোল বাবলে মিনিমাইজ হবে, কিন্তু **অডিও/ভিডিও ব্যাকগ্রাউন্ডে চলতেই থাকবে** (WebView কখনো remove হয় না, শুধু 1x1 সাইজে স্ক্রিনের বাইরে রাখা হয়)
  - বাবলে ট্যাপ করলে আবার বড় উইন্ডোতে ফিরে আসবে
  - X বাটনে ক্লিক করলে সম্পূর্ণ বন্ধ হবে, তখনই অডিও থামবে (এটাই স্বাভাবিক)

## ৫.১ "ব্যাকগ্রাউন্ডে অডিও চলতে থাকা" জিনিসটা কীভাবে কাজ করে
আগে যে সমস্যাটা ছিল (মাইনাস চাপলে গান বন্ধ হয়ে যাওয়া), সেটা হতো কারণ মিনিমাইজ করার সময় WebView-কে উইন্ডো থেকে পুরোপুরি সরিয়ে ফেলা হতো। এবার `FloatingWebBubbleService.kt`-এ WebView-টাকে **কখনোই সরানো হয় না** — শুধু তার সাইজ 1x1 পিক্সেল করে স্ক্রিনের বাইরে (কোণায়) রাখা হয়, আর তার জায়গায় একটা আলাদা ছোট বাবল আইকন দেখানো হয়। যেহেতু WebView-টা টেকনিক্যালি এখনো অ্যাটাচড ও ভিজিবল, তাই Chromium এটাকে "ব্যাকগ্রাউন্ড ট্যাব" মনে করে না, ফলে অডিও/ভিডিও চলতেই থাকে।

## ৬. যা পরের ধাপে করতে হবে
- `Home` ও `My Floating Apps`-এর ডেমো অ্যাপ লিস্টের জায়গায় ফোনের আসল ইনস্টল করা অ্যাপের লিস্ট আনা (PackageManager দিয়ে)
- "All online apps" সেকশনের জন্য জনপ্রিয় অ্যাপের ওয়েব লিংকের একটা রিয়েল লিস্ট বানানো
- Overlay পারমিশন রিকোয়েস্ট MainActivity-তে যোগ করা
- ফ্লোটিং বারে ট্যাপ করলে কী খুলবে (অ্যাপ লিস্ট পপআপ ইত্যাদি) সেই লজিক `toggleBarExpanded()`-এ বসানো

কোন ধাপটা নিয়ে এগোতে চাও বল — এরপর সেটা ধরে ধরে করে দিই।
